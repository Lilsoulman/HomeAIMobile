# HomeMind 统计页 UI 与功能参考

## 目的

本文件记录 2026-08-01 提供的两张参考图中可见的视觉规则、功能入口和统计口径，供后续实现番茄、计划、倒数、待办圈及真实统计聚合时使用。

参考图展示的是效率管理应用的统计首页，有浅色信息卡版本和深色沉浸版本。当前 Flutter 实现以深色版本为默认主题，并保留浅色切换入口。

## 已落地界面

| 区域 | 当前实现 |
| --- | --- |
| 主导航 | 统计、待办、番茄、计划、日历、倒数、我的，共 7 个入口 |
| 统计首页 | 8 个指标卡、完成率环、近 7 天柱状趋势、近 4 周热力图 |
| 待办 | 全部/未完成/已完成筛选、看板/列表切换、新增待办、完成状态切换、优先级与分类展示 |
| 日历 | 月视图、事件点位、按日期查看日程、新增日程 |
| 我的 | 深浅主题切换、强调色切换、提醒/备份/关于入口 |
| 番茄、计划、倒数 | 已创建统一视觉的功能入口页；计时、计划分解和倒数数据模型待接入 |

## 视觉规则

- 默认深色：页面背景接近 `#0D0D0F`，卡片为 `#18181C`，描边为 `#2D2D34`。
- 强调色：薄荷绿 `#A6D7C7`，辅助色为暖米色 `#E6D2A9`、雾蓝 `#B9C6DB`、提示红 `#EF6B70`。
- 卡片使用 16 到 24 px 圆角、细描边和轻阴影；底部导航为悬浮胶囊形。
- 层级：页面标题 30 到 32 px，卡片标题 18 到 21 px，指标数值 18 px，说明文本 10 到 15 px。
- 所有中文文案使用 UTF-8 保存，避免旧版文件中的乱码显示。

## 参考图功能点

### 顶部时间感知卡（浅色参考图）

- 根据当前时段显示“下午/晚上”、时间与问候。
- 展示当日进度条，以及两类计数 `4 / 4`、`7 / 8`。
- 引导文案：了解自己什么时间爱记事、什么时间最能干活。
- 可作为“个人效率时段洞察”模块，依赖创建待办、完成待办、番茄开始与结束的时间日志。

### 待办关键词洞察

- 待办热词：按未完成待办标题分词，显示词频和“最常写的事”。
- 已完成关键词：按完成待办标题分词，显示可复用的高频行动，并给出正向反馈。
- 参考词频：测试 7、填报 5、工时 5、接口 5、时填 5、习复 4、周学 4、复盘 4、学习 4、实例 4。
- 参考完成词：测试 x7、填报 x4、工时 x4、接口 x4、时填 x4、aiops x3。
- 实现注意：应过滤停用词、日期和纯数字；中文分词需在数据层统一处理，不能依赖 UI 字符串截取。

### 优先级分布

- 统计范围：仅未完成待办。
- 维度：高、中、低优先级，使用横向进度条和数量。
- 参考值：高 0、中 1、低 9。
- 建议补充：无优先级待办的处理规则、截止时间风险提示、高优先级逾期数量。

### 待办类目占比

- 用环形图展示所有待办数量，右侧列出分类数量。
- 参考总量：41。
- 参考分类：默认 25/34、工作 4/5、学习 1/1、健康 1/1。分子/分母需在产品中明确是“完成/总数”还是“未完成/总数”。
- 分类应支持颜色、图标、排序及空分类隐藏。

### 番茄与专注统计

- 参考指标：今日番茄 0 个、今日专注 0 分、连续专注 0 天、本周专注 0 分、本月专注 0 分、累计番茄 0 个。
- 需要的最小数据：开始时间、结束时间、计划分钟数、实际分钟数、关联待办、是否中断。
- 连续天数建议按“当天至少完成一个有效专注段”计算，并明确跨时区规则。

### 总体待办统计（深色参考图）

| 指标 | 参考展示值 | 建议口径 |
| --- | ---: | --- |
| 今日完成 | 13 | 完成时间落在本地自然日的待办数 |
| 今日新增 | 10 | 创建时间落在本地自然日的待办数 |
| 进行中 | 10 | 未完成且未归档的待办数 |

| 已逾期 | 4 | 未完成且截止时间早于当前时间 |
| 今日到期 | 0 | 未完成且截止日期为本地自然日 |
| 高优先 | 0 | 未完成且优先级为高 |
| 均完成用时 | 22.1 小时 | 完成时间 - 创建时间的平均值 |

### 完成率详情

- 环形图显示完成率，旁边显示总量、已完成数、本周完成、周环比、近 7 日日均完成量。
- 参考值：共 41 项，已完成 31；本周完成 31；上周 0，增加 31；近 7 日日均完成 4.4 项。
- 按时完成率：`截止前完成数 / 有截止时间且已完成数`；参考值 40%，即 8/20。
- 子任务推进：参考值 0/1。后续待办模型需支持子任务和独立完成状态。

### 趋势与热力图

- 近 7 天完成待办：按本地自然日分组的完成数。参考值从周六到今日为 0、0、0、0、1、17、13。
- 近 4 周完成热力：7 列 x 4 行，每格表示一天；颜色由当日完成数或专注分钟数映射，颜色越亮表示越努力。
- 需要支持空数据、未来日期、周起始日配置和无障碍文本说明。

## 后续数据与实现建议

1. 把示例数据替换为持久化数据源，并为待办增加 `createdAt`、`completedAt`、`dueAt`、`archivedAt`、`subtasks`、`categoryId`。
2. 独立建立统计聚合层，按日缓存指标，避免在 Widget 内进行复杂计算。
3. 为统计口径编写单元测试，尤其覆盖时区边界、逾期、按时完成率和周环比。
4. 接入番茄计时后，再启用今日专注、连续天数和热力图的真实数据。
5. 对关键词模块引入中文分词和停用词表，并允许用户关闭行为洞察。
