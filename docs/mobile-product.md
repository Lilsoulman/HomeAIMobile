# HomeMind 移动端产品体验

## 定位

移动端是 HomeMind 的日常使用端：用户以一次触控或语音完成高频设备控制、场景执行和确认，并随时了解家庭当下状态。产品体验始终围绕“场景 → 执行 → 反馈 → 记忆”，不要求用户理解 AI、Agent、Skill、Home Assistant 或模型。

移动端与 Web 共享服务端确定的家庭、权限、场景、确认和记忆事实；客户端不直连第三方服务，不复制 Household State Engine、Trust Engine 或 Execution Engine 的决策。

## 主导航与职责

App 固定为四个底部 Tab，并提供全局悬浮语音按钮：

| 入口 | 用户目标 | 移动端职责 |
| --- | --- | --- |
| 首页 | 了解此刻家庭状态 | 问候语、当前环境、一个最可能动作、最近场景、家庭状态与最近自动调整的撤销入口；不加载完整设备列表 |
| 场景 | 快速完成常用事务 | 查看回家、离家、观影、睡眠等场景；预览动作、解释、确认要求和逐步骤真实结果 |
| 设备 | 直接控制已授权设备 | 按空间查看标准化设备状态，并以触控或语音完成高频控制；展示实际结果或明确失败原因 |
| 我的 | 管理个人使用内容 | 查看、修改或删除自己的习惯；查看账户和会话状态；不提供家庭级治理配置 |

页面文案只描述用户可感知的事实，例如“客厅灯已开启”“睡眠模式部分完成”。不得将“智能推荐”“Agent 规划”、模型过程、Skill 名称、HA 服务名或实体 ID 暴露给用户。

## 与 Web 的分工

| 能力 | App（使用端） | Web（管理端） |
| --- | --- | --- |
| 设备控制与场景执行 | 语音和一键执行 | 仅查看、配置与审计，不作为日常遥控器 |
| 确认 | 接收推送并以触控或语音处理 | 在确认中心同步处理，不发送系统推送 |
| 首页与健康 | 当前环境、一个动作、最近状态和简明异常 | 全屋状态、日志、筛选和失败治理 |
| 家庭与信任 | 只读家庭信息和个人习惯 | 成员、家庭场景实例、信任策略与连接配置 |
| 设备、场景与记忆配置 | 不配网，不编辑复杂规则 | HA 连接、发现、设备分组、场景规则和批量治理 |

任一端处理确认、重试或撤销后，另一端必须刷新为服务端的同一终态。App 不得自行推断成功、提升信任等级或默认执行动作。

## 核心体验流程

1. 登录并恢复会话后，以服务端会话初始化当前家庭和角色；家庭 ID 不能由 URL、缓存或用户输入覆盖。
2. 首页按“当前状态 → 一个最可能动作 → 最近一次场景 → 异常”展示服务端事实。数据未发布或不可用时展示受控空态或错误态，不显示示例数据。
3. 用户从场景或语音入口发起行动时，先展示可理解的动作清单、影响范围、解释和服务端给出的确认要求；确认请求使用新的幂等键，提交期间禁止重复操作。
4. 执行后仅以 HA 状态回读或服务端事件确认的结果展示“全部完成”“部分完成”“失败”“取消”或“超时”。部分失败只提供失败步骤的重试；“恢复之前状态”始终发起新的可审计执行。
5. 已认证用户的主动设备调整可产生个人偏好候选。用户只在“我的习惯”看到可理解的结果，并可修改或删除单条；自动执行、匿名操作和人工优先窗口本身不写成个人偏好。

所有异步页面和表面必须提供 loading、empty、error、retry 四态。写操作、确认和重试期间必须禁用重复提交；页面释放或进入终态后停止轮询。

## 安全与数据边界

- 客户端只访问 HomeMind API，只消费标准化空间、设备、能力、状态、场景和确认结果。
- 不保存或展示 HA Token、HA URL、第三方凭据、Prompt、模型思考过程、原始实体 ID、原始状态、完整设备日志、绝对路径或完整 API 响应。
- 家庭、权限、设备信任、场景生命周期、确认超时、人工优先窗口及是否执行，均由服务端引擎裁决。`403`、`404`、`409`、`422` 和依赖不可用必须如实呈现。
- 高风险、未建立信任、批量或未分类动作必须等待服务端的显式确认裁决；客户端不自行倒计时、取消或默认执行。
- 仅 `owner` / `admin` 能在 Web 端管理 HA、密钥、成员、信任和复杂场景规则。移动端不回显任何密钥或连接配置。
- 财务、缴费、快递、宠物、家庭日程、出游、专家/Skill 工作台及其他 R1 下线领域不再有移动端入口或产品说明。
