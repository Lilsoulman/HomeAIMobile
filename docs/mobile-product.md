# HomeMind 移动端产品体验

## 定位

移动端用于高频、即时的个人与家庭操作：查看概览、处理提醒和确认、记录计划、使用轻量 AI 能力。它和 Web 共享同一 API、家庭和权限边界，不直连第三方服务或复制服务端决策。

## 主导航与职责

| 入口 | 用户目标 | 典型能力 |
| --- | --- | --- |
| 管家 | 快速了解家庭状态 | Dashboard、动态、设备健康、确认入口 |
| 能力 | 触发个人 AI 与轻量工具 | 专家、生活建议、轻量剪辑入口 |
| 待办 | 管理当日安排 | 待办、日历、确认任务 |
| 家庭 | 共享家庭上下文 | 成员、知识、决策、家庭提醒 |
| 设置 | 管理个人偏好和连接状态 | AI 配置、收藏、个人连接、账号 |

计划入口中的旅行视图承载“圆周计划”式的行程阅读体验：以旅行摘要、进行状态、完成进度和纵向时间线帮助用户快速扫描多日安排。它只聚合已经确认写入 NexusMind 日历的事件；创建行程继续使用生活专家的生成、影响范围展示和幂等确认流，未生成或未确认时不展示假计划。

## 与 Web 的分工

- 移动端承载随时查看、快速确认、记录和轻量发起。
- Web 承载 Connector 家庭级配置、成员授权、自动化治理，以及复杂剪辑、思维导图和大屏管理。
- 两端都只能使用已发布的后端 API。没有字段级契约时隐藏入口或维持受控状态，绝不显示假数据。

## 核心体验流程

1. 登录、恢复会话并进入管家首页；家庭 ID 和角色由服务端会话决定。
2. 领域页面拉取事实数据，始终提供 loading、empty、error 与 retry。
3. 对设备、自动化或 AI 动作显示影响与确认要求；用户确认后发送幂等请求。
4. 运行类操作保存 `runId`，展示公开事件并轮询到 `completed`、`failed` 或 `cancelled`；重进页面能恢复结果。

## 安全与数据边界

旅行计划只显示日历事件的标题、标准化时间、地点和描述等公开字段，不显示供应商协议字段、原始事件载荷或外部凭据。移动端不提供交通、住宿或支付代订入口；需要生成时跳转现有行程规划，确认后才同步到日历。

家庭财务入口位于家庭页，提供近 30 天汇总、流水查看、CSV 文本预览导入、缴费账户结构化建档、已缴登记、到期提醒和年度缴费趋势；提醒可跳转确认中心，趋势只展示服务端按实际缴费月份聚合的结果。移动端不上传图片/原始票据、不保存账户号码，也不提供支付入口。

快递管家入口位于家庭页，用户可登记个人运单、查看服务端脱敏后的状态、手动刷新物流及查看站内异常建议。移动端不显示或持久化完整运单号，不提供催件、改址、下单或其他第三方操作入口。

宠物管家入口位于家庭页，提供宠物档案、未来七天照护与用品余量提醒。移动端只提供家庭内提醒和库存记录，不提供诊断、医疗建议、购买、下单或支付入口。

家庭日程协同入口位于家庭页，提供未来七天聚合日程、跨成员冲突、共同空档、到期提醒和明日预览；可添加仅含证件类型、家庭内展示名称和到期日的提醒。移动端不展示或存储证件号码、照片、原件、日历提供商字段，也不自动改期、写入外部日历或执行提醒关联动作。

- 客户端只访问 HomeMind API，不保存第三方 Key、Connector 凭据、Prompt、模型思考过程或原始 Provider 数据。
- 使用 `flutter_secure_storage` 保存会话；`env/.env` 只能含开发地址，不能放秘密。
- 不渲染设备实体 ID、完整运单号、原始账单/证件、绝对文件路径和完整错误载荷。
- 前端权限仅改善导航体验；所有真实授权由 API 的 `403` 和资源可见性决定。
