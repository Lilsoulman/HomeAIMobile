# HomeMind 移动端 UI 风格指南

## 目的

HomeMind 是功能导向的家庭控制产品。界面只呈现用户可理解的家庭状态、场景动作、真实执行结果和个人习惯；不得把 AI、Agent、Skill、模型推理、HA 服务名或协议字段作为产品概念展示。不得添加装饰性渐变、悬浮装饰或与任务无关的图像。

## 设计令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 电光蓝 | `#4DA3FF` | 主操作、选中状态和活动控件 |
| 薄荷绿强调色 | `#3DD6A0` | 系统健康状态和已确认完成状态 |
| 正文文本 | `#1A1A1A` | 浅色模式的主要文本 |
| 深色背景 | `#1C1C1E` | 深色模式背景 |
| 深色内容表面 | `#2C2C2E` | 深色模式卡片、底部弹层和表单字段 |
| 深色主要文本 | `#FFFFFF` | 标题和关键数值 |
| 深色正文文本 | `#A1A1AA` | 描述和控件文本 |
| 深色元数据 | `#71717A` | 时间戳和次要信息 |
| 页面内边距 | 水平 `20px`，垂直 `24px` | 可滚动页面默认内边距 |
| 表面圆角 | `20px` | 独立信息或状态表面 |
| 控件圆角 | `16px` | 按钮、标签和输入框 |
| 主区块间距 | `24px` | 页面锚点、控件组和信息区块之间 |
| 关联控件间距 | `12px` | 控件之间及重复信息表面之间 |
| 底部内容内边距 | `100px` | 悬浮导航上方的可滚动 Tab 内容 |

Flutter 的唯一令牌来源为 `lib/core/ui/nexus_theme.dart`。页面使用 `Theme.of(context)`、`NexusLayout` 和共享 `ColorScheme`，不得在功能页重复定义颜色、阴影、圆角或间距。

## 首页参考布局

移动端采用简洁、留白充足的家庭控制界面：浅色主题以白色圆角表面承载内容，主色只用于选中状态、图标底板和唯一主操作。底部导航使用悬浮圆角 Surface，中间预留语音入口；图标和文字始终成组显示，当前 Tab 使用主色强调。首页由问候、家庭状态主卡、一个建议区和最近活动区组成，卡片避免堆叠装饰与冗余描边。家庭状态主卡可使用 `ColorScheme.inverseSurface` 形成单一高对比锚点，文字和图标必须对应使用 `onInverseSurface`；不得通过硬编码黑色或渐变模拟该层级。

当家庭状态、设备或场景 API 尚未发布或无法验证时，沿用相同卡片层级展示明确的受控不可用状态；不得用示例温度、房间、设备、场景或执行记录填充界面。个人页采用资料卡与设置列表卡，保持单列、可扫描的设置层级。

## 页面层级

- 首页依次呈现问候语、当前环境、一个最可能动作、最近场景和异常/“全部正常”；完整设备列表只能出现在设备 Tab。
- 场景页先展示预览的动作清单、影响范围、解释和确认要求，再提供一个明确的执行或确认主操作。未有服务端预览时，不展示假动作。
- 设备页按空间或设备类型组织已授权设备，支持即时状态和高频控制；原始实体 ID、信号值、协议字段和不安全控制不出现。
- 我的页只呈现个人习惯的可解释结果与单条操作；`source`、置信度、条件、权重和原始事件不直接展示。
- 每页最多一个主操作。场景执行与确认使用 `FilledButton`；次级操作使用克制的描边控件。主命令高度至少 52px。

## 状态与结果

- `NexusSurface` 是默认信息块，避免无意义的嵌套表面。每个异步表面都必须有加载、空、错误与重试状态，Repository 调用只能在 `initState` 或用户操作中发起。
- 场景结果必须明确标记全部完成、部分完成、失败、取消或超时；成功步骤与失败步骤分开显示，仅对可重试步骤显示重试入口。
- 确认卡包含标题、影响范围、风险、时间以及确认/拒绝操作；已解决项只读。风险与设备/场景健康颜色仅从 `NexusPalette` 取值。
- 自动化健康在 App 只显示简明状态、暂停原因和需处理事项；日志、筛选和批量治理属于 Web。不得声称设备故障预测。
- 共享状态组件保留 `RiskBadge`、`ConfirmationCard` 与 `StewardTimelineTile`；显示文字须使用家庭状态和场景语言，而非 AI 产品词汇。

## 排版与响应式

页面锚点为 28px/700，区块标题为 18px/600，正文与控件为 15px/400–500，元数据为 13px/400。支持 320px 至 430px 宽度，使用 `Expanded`、`Wrap`、可滚动快捷操作行和 `SafeArea`；标签可换行，但不得截断关键信息、重叠或使用固定内容宽度。

浅色和深色主题必须由共享主题维护；功能页面不得硬编码白色、黑色或灰色。
